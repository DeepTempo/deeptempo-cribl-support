# DeepTempo Intelligent Defense for Cribl — support

This repository tracks non-sensitive issues with the DeepTempo Intelligent Defense app for Cribl. The app reads Vigil findings, displays LogLM detection context and prepares telemetry integration plans.

## Report a problem

[Open an issue](https://github.com/DeepTempo/deeptempo-cribl-support/issues/new) with:

- App version and Cribl version.
- The affected page and a short sequence of steps to reproduce the problem.
- Expected behavior, actual behavior and a sanitized error message.
- Whether the app is installed persistently or running in Live Preview.

Public issues are visible to everyone. Do not attach credentials, customer data, findings, raw telemetry, private deployment URLs or confidential screenshots. Reproduce with synthetic data when possible. For a report that cannot be made public, use the [DeepTempo contact form](https://www.deeptempo.ai/contact-us) and identify **DeepTempo Intelligent Defense for Cribl**.

## Report a security vulnerability

Contact [security@deeptempo.ai](mailto:security@deeptempo.ai) privately. Do not open a public issue with exploit details. Include the app version and a concise description of the suspected impact; wait for a private response before sending sensitive supporting material.

## Scope and maintenance

DeepTempo owns this support repository. Alex Margaris is the initial support contact. App installation and configuration instructions are included in the README shipped with each app package. This repository contains support documentation and issue tracking only; it does not publish app source, credentials or customer data.

For Cribl platform problems independent of the app, use your organization's normal Cribl support channel.
